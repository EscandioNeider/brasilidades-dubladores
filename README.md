# 💚Brasilidades: Dubladores Brasileiros💛

Este site faz parte de um projeto da unidade SENAI chamado "Brasilidades", onde os alunos do curso de DS fizeram um site com coisas típicas do Brasil. O meu site é dedicado aos grandes dubladores do Brasil, destacando suas vozes icônicas e trajetórias marcantes.  

## O que você encontra aqui?
- 🎙️ Informações, curiosidades e áudios de dubladores lendários;
- 🎨 Um visual escuro e elegante, feito para valorizar o conteúdo principal;
- ♿ Recursos de acessibilidade ARIA, garantindo inclusão para todos os visitantes;

🔗Acesse meu projeto: https://escandioneider.github.io/brasilidades-dubladores/
